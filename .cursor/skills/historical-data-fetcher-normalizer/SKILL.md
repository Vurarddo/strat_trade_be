# Historical Data Fetcher & Normalizer

Description: Інструмент для підготовки датасетів для бектестингу.

Input: Тикер активу, таймфрейм, діапазон дат.

Process: Завантажує історичні дані (можливо, з локального архіву або через API). Перейменовує колонки в стандартний формат, конвертує час у потрібну таймзону, заповнює пропущені свічки.

Output: Зберігає очищений DataFrame у форматі .parquet або .csv для швидкого доступу при масових бектестах.

## Інструкції для агента

1. **Джерело**: реалізувати або викликати наявний **`CandleFeed`** / адаптер (broker, файл, Parquet-архів) у **`adapters/`**; не тягнути HTTP/SDK у **`domain/`**.
2. **Схема**: колонки **`Open`**, **`High`**, **`Low`**, **`Close`**, **`Volume`** (або зіставлення з доменним `Candle` → DataFrame на межі); індекс або колонка часу — **UTC** за замовчуванням; дедуп за `open_time`.
3. **Пропуски**: явна політика (resample + forward-fill обмежено, або порожні рядки з NaN з подальшою фільтрацією) — зафіксувати в коді/доксі, щоб бектест був відтворюваним.
4. **Збереження**: **`parquet`** для швидкості та типів; **`csv`** для сумісності — шлях артефакта поза git або в узгодженій директорії даних (див. `.gitignore`).
5. **Параметри**: тикер, таймфрейм, `start`/`end` передавати через CLI/конфіг/Pydantic, без хардкоду секретів для API.

Узгоджувати з **`trading-backend-architecture-backtesting.mdc`** та **`dataframe-indicator-pipeline`** (NaN після TA — на етапі стратегії, не обов’язково в цьому кроці, якщо зберігають сирі нормалізовані свічки).
