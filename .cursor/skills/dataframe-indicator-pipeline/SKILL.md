# DataFrame Indicator Pipeline

Description: Інструмент для конвертації сирих ринкових даних у підготовлений для аналізу формат.

Input: Сирі JSON-дані або словники з OHLCV котируваннями від брокера.

Process: Трансформує вхідні дані у pandas.DataFrame, автоматично застосовує базовий набір налаштованих індикаторів через pandas-ta (наприклад, EMA, об'єми) та очищає фрейм від невалідних значень.

Output: Повертає чистий DataFrame, готовий для зчитування стратегічною логікою бота.

## Інструкції для агента

1. **Парсинг**: зіставити поля брокера з колонками OHLCV; індекс — час свічки (UTC); відсортувати, прибрати дублікати за часом.
2. **Індикатори**: застосувати узгоджений «базовий» набір (EMA, volume-derived тощо) через **pandas-ta** як у специфікації; параметри виносити в константи або конфіг.
3. **Очистка**: видалити/позначити рядки з невалідним OHLC (high < low, від’ємний volume за політикою); після індикаторів — явна політика щодо **NaN** до будь-яких сигналів (див. `python-trading-architecture-clean-code.mdc`).
4. **Шари**: сирий JSON — лише в **`adapters/`**; функція пайплайну приймає вже нормалізовані dict/records або DataFrame, без мережевих викликів усередині.

## Репозиторій Strat Trade

У `pyproject.toml` зараз оголошено **`ta`**, не `pandas` / `pandas-ta`. Якщо реалізуєш цей пайплайн тут — додай залежності в `pyproject.toml` і тримай межу між **`Candle`** (домен) та DataFrame (аналітика) явною.
