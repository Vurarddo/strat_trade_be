# Safe Trade Executor

Description: Обгортка навколо функцій виконання ордерів BinaryOptionsTools-v2.

Input: Торговий сигнал (напрямок, актив, сума, час експірації).

Process: Спочатку валідує поточний баланс рахунку. Потім перевіряє активний режим середовища (запобігає випадковому використанню реальних коштів під час розробки). Відправляє запит брокеру.

Output: Повертає структурований статус угоди (Успіх/Помилка/Таймаут) для системи логування ризиків.

## Інструкції для агента

1. **Шар**: реалізація лише в **`adapters/`** як реалізація **`TradingGateway`** (або вузький модуль, який викликає порт); **`domain/`** і **`use_cases/`** — без імпорту BinaryOptionsTools-v2.
2. **Режим**: читати **demo vs live** з **Settings** / env; перед відправкою ордера явно перевіряти очікуваний режим і відмовляти, якщо сигнал не відповідає політиці (наприклад, live заборонено в dev).
3. **Баланс**: отримати баланс через той самий шлюз або кешований знімок з узгодженим TTL; порівняти з сумою у сигналі; повертати помилку валідації без мережевого ордера, якщо недостатньо коштів.
4. **Мережа**: таймаути, обмежені ретраї, `try`/`except` на межі I/O; таймаут мапити на статус **Таймаут** у вихідній структурі.
5. **Секрети**: SSID і ключі лише з env/settings; не логувати сирі облікові дані.
6. **Логування ризиків**: одна стабільна схема події (напрямок, актив, сума, режим, correlation id, кінцевий статус).
